# 使用手册

> 面向使用者：备考 2026 下半年软考中级软件设计师的考生

## 1. 启动网站

```bash
npm install    # 首次使用安装依赖
npm run dev    # 启动，浏览器打开终端提示的地址（默认 http://localhost:5173）
```

> 数据保存在当前浏览器中。换电脑/换浏览器请先在「设置」页导出 JSON，再到新环境导入。

## 2. 备考全景：这个网站怎么用

距 10 月 24 日开考约 7 周，建议节奏：

1. **第 1~4 周（学+练）**：每天在「知识点」过 1~2 章，随后到「章节练习」刷对应模块 15~20 题；错题隔天在「错题本」重练清零。
2. **第 5~6 周（测）**：每周 2~3 次「整卷模考」，重点看成绩报告中的**模块得分率排行**，最弱的两三个模块回炉「知识点」+ 错题。
3. **最后 1 周（下午题）**：「案例分析」专项每天一道大题（数据流图/数据库/UML 是拿分主力，务必练熟），保持每天一套上午卷手感。

## 3. 各功能页说明

### 📊 仪表盘（首页）
- **倒计时**：默认 2026-10-24，如你的批次不同，到「设置」改日期。
- **模块正确率条**：刷满 10 题后显示，绿色≥80%、黄色≥60%、红色<60%——红色模块优先补。
- **今日目标**：默认 30 题/天，可在设置调整。

### 📚 知识点
12 大模块 → 章节 → 正文。**必考/常考**标签直接告诉你优先级；读完点右上角「标记掌握」，进度计入首页。章节末尾有「去刷本模块题目」直达入口。

### 📐 公式速查
上午卷计算题的"口袋公式"：8 大分组 50+ 条高频公式（流水线、Cache、可靠性、PV 操作、子网划分、McCabe、关键路径、挣值、二叉树性质、图像/音频容量等）。顶部支持关键词搜索（如输入"子网"直达子网划分），点「🔥 只看高频」过滤出必背条目——考前一周每天过一遍。

### ✏️ 章节练习
- 选模块（可再按章节/随机筛选）→ 逐题作答 → 提交后立即判分并展开解析。
- 题库含 **2020—2024 历年上午真题 165 题**（解析标注来源年份），与精编题混合；**🔥 高频**标签的题优先做；「☆ 收藏」的题可在设置导出前反复回顾。
- 真题解析较短的题，可点「AI 深度讲解」获取通俗展开。
- 答错的题自动进错题本。

### ⏱️ 整卷模考（重点：模拟真实机考）
规则与真实考试一致：
1. 点「开始模考」智能组卷 75 题（按真题各模块题量分布）。
2. **上午卷**：顶部实时显示总剩余时间与上午剩余时间；答题卡可跳题、🚩 标记疑问；**开考 90 分钟内不能交卷**（真实规则），满 120 分钟自动交卷。
3. 交卷后选择 **C++ 或 Java**（对应真实考试的试题五/六二选一）。
4. **下午卷**：5 道案例大题，在文本框作答后展开「对照参考答案与评分要点」，**如实自评打分**（自评严格一点，考场才有安全边际）。
5. 「完成考试」后可在首页与模考入口的历史记录中查看**成绩报告**：两科得分、各模块得分率（从弱到强排序）、逐题解析（可切换"仅看错题"）。
- **中途刷新/关闭浏览器不丢进度**，计时以开考时刻为准；「放弃考试」不保存成绩。

### 📝 案例分析专项
五大题型分类练习（数据流图、数据库设计、UML、算法填空、C++/Java 面向对象），含 2022 上半年下午真题（矩阵链乘动态规划、备忘录模式 C++/Java）。作答草稿自动保存，每道大题底部附**💡 解题套路**，考前务必过一遍。

### 📕 错题本
- 按模块筛选查看，展开可见正确答案 + 解析 + 你的最后错选。
- 「🔄 重练错题」逐题重做，**答对自动移出**；建议每周清零一次。

### 🤖 AI 功能（先到「设置」页配置接口）

**配置一次，四 处可用**：设置页选择预设（智谱 GLM——注册送额度且 glm-4-flash 免费 / DeepSeek / Ollama 本地），填入 API Key（Ollama 无需），点「测试连接」验证。Key 只保存在你本机浏览器。

| 功能 | 入口 | 用途 |
| --- | --- | --- |
| AI 答疑助手 | 任意页面右下角 🤖 悬浮按钮 | 随时提问知识点，先结论后要点、带计算步骤和口诀 |
| AI 深度讲解 | 任意题目判分后的解析区 | 通俗讲解 + 每个错误选项错在哪 + 同考点变式题（附答案） |
| AI 智能出题 | 侧边栏「AI 出题」 | 选模块/考点/难度，无限生成真题风格新题；**好题点"存入题库"，进入章节练习反复刷** |
| 案例题 AI 评分 | 案例作答卡底部 | 按评分要点逐条对照你的作答给分，指出漏答点与提分建议 |

> 提示：题库刷穿后主力靠「AI 出题」保持手感；AI 出的题做完判分同样自动进错题本。

### ⚙️ 设置
考试日期、每日目标、AI 接口配置与测试连接、AI 题库管理、数据导出/导入、清空数据、深浅色主题（侧边栏底部切换）。

## 4. 常见问题

| 问题 | 答案 |
| --- | --- |
| 刷新后学习记录还在吗？ | 在。记录存在浏览器 localStorage，模考计时也会恢复。 |
| 换电脑怎么迁移？ | 旧电脑「设置→导出数据」下载 JSON，新电脑「导入数据」上传。 |
| 模考为什么不能提前交卷？ | 真实机考上午卷最短需作答 90 分钟，网站按真实规则限制。 |
| 下午题怎么算分？ | 机考由阅卷评分，网站采用"对照参考答案自评"模式，重点看得分点是否覆盖。 |
| 及格线是多少？ | 两科满分各 75，**均需 ≥45 且同时达标**，单科成绩不保留。 |
| 想补充真题怎么办？ | 按《开发文档》的题库格式在 `src/data/questions/` 追加即可。 |
