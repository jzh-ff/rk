# 软考软件设计师 · 学习与练习网站

面向 **2026 年下半年（10 月 24 日—27 日）软考中级软件设计师** 的本地学习与练习网站，覆盖「学、练、测、纠」完整闭环。

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 📊 仪表盘 | 考试倒计时、刷题量/正确率、14 模块正确率、每日目标进度、模考历史 |
| 📚 知识点学习 | 按官方考纲组织的 14 大模块精讲（含多媒体、软件架构与新技术），常考等级标注，掌握进度跟踪 |
| ✏️ 章节练习 | 按模块/章节刷题，顺序或随机，即时判分 + 详细解析，自动收录错题 |
| ⏱️ 整卷模考 | 按真题题量分布智能组卷 75 题；模拟真实机考连考规则（总 240 分钟、上午最长 120 分钟/最短 90 分钟、节余时间带入下午）；下午 4 必答 + C++/Java 二选一；成绩报告含模块得分与逐题解析 |
| 📝 案例分析专项 | 数据流图 / 数据库设计 / UML / 算法填空 / 面向对象五大题型，作答草稿自动保存，对照参考答案自评 |
| 📕 错题本 | 自动收集错题、按模块筛选、重练模式（答对自动移出） |
| 🤖 AI 功能 | **AI 答疑助手**（全局随时问）、**AI 深度讲解**（任意题目通俗讲解+举一反三）、**AI 智能出题**（按模块/考点无限生成，好题存入题库）、**案例题 AI 评分**（按评分要点自动阅卷）。支持智谱 GLM / DeepSeek / Ollama 本地等 OpenAI 兼容接口，Key 仅存本机 |
| ⚙️ 设置 | 考试日期、每日目标、AI 接口配置与测试、学习数据导出/导入（JSON）、深浅色主题 |

## 🚀 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（浏览器打开提示的地址）
npm run build   # 生产构建
```

学习数据保存在浏览器 localStorage 中，可随时在「设置」页导出 JSON 备份、换机导入。

**线上地址**：https://jzhm.fun/ruankao/ （发布：`bash scripts/deploy-local.sh`，详见[开发文档](docs/开发文档.md)）
